# 🚀 C++ DSA Problem Tracker

A console-based application built using **C++** to organize LeetCode problems, track solved and unsolved questions, and monitor DSA preparation progress.

## 📌 Features

* 📚 **Browse by Topic** — Explore problems organized by DSA topic.
* ✅ **Track Progress** — Mark problems as solved or unsolved.
* 📋 **View Unsolved Problems** — See which problems remain.
* 📊 **Progress Statistics** — Monitor your preparation progress.
* 💾 **Save Progress** — Store your problem statuses in a file.
* 🔍 **Filter by Difficulty** — Find Easy, Medium, and Hard problems.
* 🔎 **Search Problems** — Search using a LeetCode problem number or name.
* 🔄 **Persistent Storage** — Load saved progress when you restart the application.

## 🛠️ Technologies Used

* C++
* Standard Template Library (STL)
* Vectors and Structures
* Functions and Loops
* File Handling (`ifstream` and `ofstream`)

## ⚙️ How to Run

### Prerequisites

* A C++ compiler, such as GCC or MinGW-w64.
* Visual Studio Code (optional).

### Steps

1. Clone or download this repository.

2. Open the project folder in your terminal.

3. Compile the program:

   ```bash
   g++ main.cpp -o main
   ```

4. Run the program on Windows:

   ```bash
   .\main.exe
   ```

## 💾 Progress Storage

The application stores problem statuses in `progress.txt`, allowing your progress to be restored when you reopen the application.

**Tip:** Save your progress before closing the program.
